## Cross-Phase Validation Checklist:
Before starting any phase, verify:
1. Previous phase deliverables exist
2. Database schema matches expected
3. Service classes are in correct namespaces
4. No business logic in controllers (audit if needed)
5. Tests from previous phase pass

## Emergency Rollback Plan:
If a phase breaks previous functionality:
1. Revert to previous git tag
2. Restore database from backup (before this phase)
3. Report specific breaking changes
4. Re-attempt phase with additional test coverage

## Key Benefits of This Approach:
- **Modular**: Each phase is independent
- **Testable**: Each phase has validation criteria
- **Recoverable**: If a phase fails, rollback to previous phase
- **Parallelizable**: Different developers can work on different phases
- **Budget-friendly**: Pay only for phases you need

## Critical Reminders for Each Chat:
- **NEVER** put business logic in controllers
- **ALWAYS** use DTOs for data transfer
- **TEST** before claiming completion
- **DOCUMENT** handoff data

This prompt ensures every AI chat understands exactly what to build, what NOT to build, and how to hand off to the next phase.
